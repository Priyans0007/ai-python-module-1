## 🧠 AI, Machine Learning, and Deep Learning

### Artificial Intelligence (AI)

AI is the broader concept of machines performing tasks that require human-like intelligence.

### Machine Learning (ML)

Machine Learning is a subset of AI in which computers learn patterns from data and use those patterns to make predictions or decisions.

### Deep Learning

Deep Learning is a subset of Machine Learning that uses multi-layer neural networks to learn complex patterns from large amounts of data.

### Difference

| Technology    | Description                                 |
| ------------- | ------------------------------------------- |
| AI            | Broad field of intelligent computer systems |
| ML            | Systems learn patterns from data            |
| Deep Learning | Uses neural networks with multiple layers   |
